# Reusable Argo CD Patterns

These patterns are static reference assets used by the labs and architecture discussions.

- `appproject/` — bounded source/destination policy;
- `application/` — single Application;
- `app-of-apps/` — controlled root;
- `applicationset/` — repeated Application generation;
- `sync-waves/` — ordering/hooks;
- `ignore-differences/` — narrowly-scoped diff customization;
- `standard-6files/` — product GitOps contract.

Patterns are `REFERENCE/STATIC_VALIDATED` until executed.
