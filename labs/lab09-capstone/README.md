# Lab09 — Capstone

Combine:
- AppProject;
- Application/ApplicationSet;
- Kustomize workload;
- self-heal;
- prune;
- desired-state rollback;
- sync waves;
- operational evidence.

## Exit criteria

- all manifests static validated;
- Application Synced/Healthy;
- drift repaired;
- disposable resource pruned;
- desired state reverted and reconciled;
- no secrets in evidence;
- exact Git revision recorded.

Use `docs/09-capstone.md` as the full checklist.
